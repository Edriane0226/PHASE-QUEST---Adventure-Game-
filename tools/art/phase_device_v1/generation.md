## Original generation prompt

Use case: stylized-concept. Asset type: finished transparent game equipment sprite atlas, one single 4-column by 4-row equal-cell square atlas. Reference image 1 gives ONLY the existing explorer's soft outlined storybook game rendering style and proportions; reference 2 gives ONLY in-game prop palette, outline weight and perspective. Generate ORIGINAL equipment only, NO character, NO hands, NO body. Subject: a tiny one-hand PHASE DEVICE for this explorer, compact friendly brass-and-ivory science instrument, rounded short navy/ivory barrel, gold collars, one recessed teal circular emitter aperture, a small amber status jewel, short brown pistol-style handgrip. Silhouette should be a short thick flashlight/scanner with a grip, not a rifle. One consistent design, restrained details, flat illustrated shading with two or three tones, brown/navy clean outlines, slight upper-left lighting. No photorealism, no gradients/glare, no large crystal, no beam, no muzzle flash, no particles. Purpose: render at about 11 world pixels long against a 40 world pixel explorer, so chunky readable shape essential. All sprites isolated on real transparent background, no floor shadows, no text, no labels, no grids, no border. Exact atlas: 16 evenly sized cells with large transparent gutters; every object centered independently, never touching a cell edge. TOP TWO ROWS: held horizontal aiming device viewed from the same elevated RPG camera in eight directions. Row 1 columns 1-4: east (nozzle points screen RIGHT), southeast (nozzle points DOWN-RIGHT), south (nozzle points DOWN toward viewer, front nozzle visible), southwest (nozzle points DOWN-LEFT). Row 2 cols 1-4: west (nozzle LEFT), northwest (nozzle UP-LEFT away from viewer), north (nozzle UP away from viewer, rear visible), northeast (nozzle UP-RIGHT away). These must be eight genuine coherent perspective views of the same three-dimensional gadget, not eight copies facing right. Its grip remains visible and accessible in every aiming view. BOTTOM TWO ROWS: the exact same gadget stowed muzzle-down in a small chestnut leather belt holster, still visible trigger grip and ivory/navy top, brass belt loop, snug short holster; no belt, no person. This is the same holstered configuration from eight matching character directions: row3 E,SE,S,SW; row4 W,NW,N,NE. Holstered gadget points downward along the leg rather than firing horizontally. The eight holster views must be congruent with the upper held views' camera headings. Maintain precisely the same gadget colors, construction, scale and outline language throughout all 16 cells. Each object approximately half its cell width/height with comfortable fully transparent margin for deterministic cropping. Production sprites; preserve real alpha.

## Selected alpha-cleanup prompt

Precise production alpha cleanup of this sprite atlas. Preserve EXACTLY the same sixteen gadget sprites, design, shapes, scale, colors, orientations, order, 4 by 4 equal-cell layout and positions. Change ONLY export transparency: remove the nearly invisible low-opacity haze and scattered alpha noise in the empty gutters and outside each sprite; make all empty background and cell margins truly zero-alpha transparent. Retain smooth antialiased silhouette edges and solid opaque sprite interiors. Do not add any elements, shadows, text, glow or labels. Do not redraw or resize the gadgets. Output same square 4x4 atlas with clean genuine transparent background.

The selected image retains minor sub-visible export alpha. The render studies use the existing L1 flat-cutout shader's alpha policy, consistent with current player/prop rendering. No new shader or player color changes were made.
