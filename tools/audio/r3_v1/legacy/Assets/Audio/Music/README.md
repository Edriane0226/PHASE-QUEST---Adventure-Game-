# Original Phase Quest music

- `adventure_theme.wav`: 108 BPM, 16 bars, woodwind-style lead, plucked accompaniment, sustained harmony, and light hand drums. Menu and general adventure theme.
- `zone1_snowy.wav`: 80 BPM, 16 bars, gentle bell melody, sparse plucks, and soft sustained harmony. Zone 1 snowy exploration theme.

Both stereo scores were composed and rendered locally with `tools/compose_bgm.py`.
Ambience tails wrap across the loop boundary; the audio manager enables looping
over the full sample range. Existing music volume and mute controls still apply.
